# Analyze & Investigate

Forensics, malware analysis, and pulling the real story out of an artifact.

- [Wireshark](https://www.wireshark.org) — the standard for packet capture and protocol analysis.
- [Autopsy](https://www.autopsy.com) — free digital forensics platform (GUI for The Sleuth Kit).
- [Volatility 3](https://github.com/volatilityfoundation/volatility3) — memory forensics framework.
- [YARA](https://virustotal.github.io/yara/) — pattern-matching for identifying and classifying malware.
- [CAPEv2](https://github.com/kevoreilly/CAPEv2) — automated malware analysis sandbox (Cuckoo successor).
- [KAPE](https://ericzimmerman.github.io/KapeDocs/) — fast triage and artifact collection from Eric Zimmerman's tool suite.
- [MISP](https://www.misp-project.org) — open-source threat intelligence sharing platform.
