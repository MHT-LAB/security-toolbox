# Network & Homelab

Self-hosted infrastructure — what's actually running the lab.

- [Tailscale](https://tailscale.com) — mesh VPN built on WireGuard; free tier covers a homelab easily.
- [WireGuard](https://www.wireguard.com) — the modern, lightweight VPN protocol underneath most of the above.
- [Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview) — free type-1 hypervisor for running everything else.
- [TrueNAS CORE/SCALE](https://www.truenas.com) — free NAS operating system.
- [Pi-hole](https://pi-hole.net) — network-wide DNS filtering and ad blocking.
- [Portainer CE](https://www.portainer.io/community-edition) — free Docker/container management UI.
- [Uptime Kuma](https://github.com/louislam/uptime-kuma) — self-hosted uptime monitoring with a clean dashboard.
- [Netdata](https://www.netdata.cloud) — real-time infrastructure and performance monitoring.
