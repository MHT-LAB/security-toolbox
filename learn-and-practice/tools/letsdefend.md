# LetsDefend

Free-tier SOC analyst simulation platform — practice triaging real-looking SIEM alerts and incidents from a defender's seat, complementing the offense-heavy focus of HTB/TryHackMe.

**Links:** [Official site](https://letsdefend.io) — SaaS, no public repo.

## Overview

Most beginner platforms are offense-focused; LetsDefend flips that, simulating a SOC analyst's actual workday — reviewing alerts in a SIEM-like interface, deciding escalate/close, and investigating simulated incidents end to end.

## Install / Deploy

```text
Free account registration at letsdefend.io.
```

## Common Commands

Not applicable — browser-based SIEM-style investigation interface.

## Lab Exercise

Work through a few free-tier alert-triage scenarios, and for each one write up your reasoning as if it were a real incident ticket — that documentation habit is as much the point as the technical triage itself.
