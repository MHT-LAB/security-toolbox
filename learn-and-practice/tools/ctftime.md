# CTFtime

Event tracker/ratings for competitive CTF teams — the reference calendar for the CTF scene, not a challenge platform itself.

**Links:** [Official site](https://ctftime.org) — site-hosted, no active repo.

## Overview

CTFtime tracks upcoming and past CTF competitions worldwide, team ratings, and write-ups linked from past events — useful for finding live competitions to join and for reading how top teams solved specific challenges after the fact.

## Install / Deploy

```text
No installation — browse ctftime.org directly; optional free account for team tracking.
```

## Common Commands

Not applicable — reference/calendar site.

## Lab Exercise

Find an upcoming beginner-friendly CTF on the calendar (many run "jeopardy-style," open to anyone) and join solo or with a small team — competing under a real deadline is a different skill from untimed practice on TryHackMe/HTB.
