# TryHackMe

Guided, hands-on rooms — free tier covers most fundamentals. SaaS, no public repo.

**Links:** [Official site](https://tryhackme.com)

## Overview

TryHackMe structures learning as "rooms" grouped into paths (e.g. "Pre Security," "Jr Penetration Tester"), each walking through a topic step by step with an in-browser or VPN-connected target VM — the best fit if you want structure over open-ended challenge-hunting.

## Install / Deploy

```text
Free account registration at tryhackme.com; connect via their OpenVPN
config or in-browser AttackBox for most rooms.
```

## Common Commands

Not applicable — browser/VPN-based; use the tools covered elsewhere in this repo (Nmap, Metasploit, etc.) against each room's target.

## Lab Exercise

Work rooms in order within a learning path rather than at random — the guided structure is the actual value over raw HTB-style boxes. Start with "Pre Security," then move into "Jr Penetration Tester" once comfortable.
