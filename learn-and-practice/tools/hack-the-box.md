# Hack The Box

Pentesting labs and machines — free tier available. SaaS, no public repo.

**Links:** [Official site](https://www.hackthebox.com)

## Overview

HTB is less guided than TryHackMe — machines and challenges are largely unassisted, rewarding you for figuring things out rather than following a walkthrough. The "Starting Point" track eases new users in before the fully open machine pool.

## Install / Deploy

```text
Free account registration at hackthebox.com; connect to the lab network via
their provided OpenVPN config.
```

## Common Commands

Not applicable — connect via VPN and use the tools covered elsewhere in this repo against target machines.

## Lab Exercise

Complete the "Starting Point" track first if you're new, then move to retired free-tier machines — write your own notes/methodology as you go rather than looking up a walkthrough immediately when stuck.
