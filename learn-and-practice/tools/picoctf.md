# picoCTF

Free, beginner-friendly CTF platform built by Carnegie Mellon — the platform itself is open source, and challenges stay accessible year-round outside the annual competition window.

**Links:** [GitHub](https://github.com/picoCTF/picoCTF) · [Site](https://picoctf.org)

## Overview

picoCTF covers binary exploitation, web, crypto, forensics, and reverse engineering at a genuinely beginner-appropriate difficulty, with built-in hints — a good on-ramp before Hack The Box's less-assisted challenges.

## Install / Deploy

```text
Free account registration at picoctf.org to access the practice challenge archive.
```

## Common Commands

Varies per challenge — expect to reach for [CyberChef](../../analyze-and-investigate/tools/cyberchef.md), [Ghidra](../../analyze-and-investigate/tools/ghidra.md), and basic Linux tooling depending on category.

## Lab Exercise

Work through the "General Skills" category first to build baseline command-line/tooling comfort, then pick one other category (forensics or web) to specialize in for a few challenges.
