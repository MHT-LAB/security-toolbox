# Root-Me

Long-running free challenge site across many security domains — one of the oldest continuously-active challenge platforms, covering web, crypto, forensics, and more.

**Links:** [Official site](https://www.root-me.org) — site-hosted, no active repo.

## Overview

Root-Me has run since 2010 with a huge back catalog of challenges across nearly every security domain, entirely free — a good long-term practice source once you've worked through the more curated platforms (picoCTF, TryHackMe) and want more raw volume.

## Install / Deploy

```text
Free account registration at root-me.org.
```

## Common Commands

Varies enormously by challenge category — this is a source of practice targets, not a specific tool.

## Lab Exercise

Pick a category you're weakest in and work through its easiest 5 challenges as a diagnostic — Root-Me's categories are granular enough to target a specific skill gap directly.
