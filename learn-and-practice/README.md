# Learn & Practice

Hands-on ranges, CTFs, and reference material for building the muscle.

- [TryHackMe](https://tryhackme.com) — guided, hands-on rooms; free tier covers most fundamentals.
- [Hack The Box](https://www.hackthebox.com) — pentesting labs and machines; free tier available.
- [OverTheWire Wargames](https://overthewire.org/wargames/) — free wargames for Linux, SSH, and security fundamentals.
- [picoCTF](https://picoctf.org) — free, beginner-friendly CTF built by Carnegie Mellon.
- [VulnHub](https://www.vulnhub.com) — free downloadable vulnerable VMs for practice.
- [LetsDefend](https://letsdefend.io) — free-tier SOC analyst simulation platform.
- [CyberDefenders](https://cyberdefenders.org) — free blue-team DFIR challenges.
- [MITRE ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/) — free, browser-based technique mapping against the ATT&CK framework.
