# Detect & Respond

Monitoring, alerting, and the tools SOC/blue-team work actually runs on.

- [Wazuh](https://wazuh.com) — free, open-source SIEM and XDR platform.
- [Security Onion](https://securityonionsolutions.com) — free Linux distro purpose-built for network security monitoring and threat hunting.
- [Suricata](https://suricata.io) — high-performance IDS/IPS and network security monitoring engine.
- [Zeek](https://zeek.org) — network traffic analysis framework; pairs well with a homelab SPAN port.
- [OSSEC](https://www.ossec.net) — open-source host-based intrusion detection.
- [Velociraptor](https://docs.velociraptor.app) — live endpoint DFIR and hunting, built on VQL queries.
- [TheHive](https://thehive-project.org) — open-source security incident response platform.
