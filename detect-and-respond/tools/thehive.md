# TheHive

Open-source security incident response / case-management platform — the shared inbox where alerts from every other tool in this repo should land.

**Links:** [GitHub](https://github.com/TheHive-Project/TheHive) · [Docs](https://docs.strangebee.com/thehive/)

## Overview

TheHive turns raw alerts into trackable cases with tasks, observables, and collaboration between analysts — instead of triaging findings in Slack threads or email, every alert from Wazuh/Suricata/MISP/your honeypots lands here as a case with a clear owner and status.

## Install / Deploy

```bash
docker run -p 9000:9000 strangebee/thehive:5
# Or see the official docker-compose stack (with Cassandra + Elasticsearch) in the repo
```

## Common Commands

TheHive is primarily web-UI driven; the REST API automates the rest:
```bash
curl -H "Authorization: Bearer $TH_API_KEY" \
  -X POST https://thehive.local/api/v1/case -d '{"title":"Test case"}'
```

## Lab Exercise

Stand up TheHive, connect [Cortex](cortex.md) for observable enrichment, then manually create a case from a real alert generated by [Wazuh](wazuh.md) or your [OpenCanary](opencanary.md) honeypot — walk it through triage → investigation → closure to learn the workflow before automating alert ingestion.
