# Thinkst Canary

Commercial hardware/virtual honeypot appliance from the same team behind Canarytokens/OpenCanary — a turnkey, supported version of the same idea.

**Links:** [Official site](https://canary.tools) — commercial product, no public repo.

## Overview

Where OpenCanary is free but self-managed, Thinkst Canary is a paid appliance (physical or virtual) with vendor-managed updates, a hosted console, and additional realistic service emulations — worth knowing about even if your homelab runs the free OpenCanary instead.

## Install / Deploy

```text
Commercial purchase/trial through canary.tools — deploy the provided virtual
appliance image or physical device on an internal network segment.
```

## Common Commands

Managed through Thinkst's hosted web console — no local CLI.

## Lab Exercise

If evaluating for a client/employer, compare a Thinkst Canary trial deployment directly against [OpenCanary](opencanary.md) on the same lab segment to judge whether the managed/commercial version's extra realism and support justify the cost for that environment.
