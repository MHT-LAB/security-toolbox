# OSINT Framework

Curated index of OSINT resources by category — a navigable directory of tools and sites, not a tool itself.

**Links:** [GitHub](https://github.com/lockfale/OSINT-Framework) · [Site](https://osintframework.com)

## Overview

OSINT Framework is a tree of links organized by category (username, email, domain, IP, social media, etc.) — the fastest way to find "what tool/site covers this specific OSINT need" when you don't already know the answer.
