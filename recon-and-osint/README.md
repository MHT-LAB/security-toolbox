# Recon & OSINT

Finding and mapping what's publicly visible — before anyone else does.

- [Nmap](https://nmap.org) — the standard for network discovery and port scanning.
- [Amass](https://github.com/owasp-amass/amass) — OWASP's attack surface mapping and subdomain enumeration tool.
- [theHarvester](https://github.com/laramies/theHarvester) — pulls emails, subdomains, and names from public sources.
- [Recon-ng](https://github.com/lanmaster53/recon-ng) — modular web reconnaissance framework, built like Metasploit.
- [SpiderFoot](https://www.spiderfoot.net) — automates OSINT collection across 200+ data sources.
- [Shodan](https://www.shodan.io) — search engine for internet-connected devices; free tier covers most lookups.
- [Maltego CE](https://www.maltego.com/community-edition/) — free tier of the standard link-analysis tool for mapping entity relationships.
