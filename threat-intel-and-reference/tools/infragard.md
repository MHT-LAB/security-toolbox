# InfraGard

FBI-affiliated public-private partnership for critical-infrastructure threat information sharing — free membership, vetting required.

**Links:** [Official site](https://www.infragard.org)

## Overview

InfraGard connects private-sector critical-infrastructure organizations with the FBI for threat information sharing, training, and networking — membership requires an application and vetting process, but is free once approved.

## Install / Deploy

```text
Apply for membership at infragard.org; requires identity verification and
approval by a local InfraGard chapter.
```

## Common Commands

Not applicable — a membership organization, not a tool.

## Lab Exercise

If your organization touches critical infrastructure (or you work in a related sector), apply for InfraGard membership and attend a local chapter meeting to see what threat-sharing actually looks like in practice.
