# Cyber Threat Alliance

Vendor-neutral nonprofit coordinating threat-intel sharing across member security vendors — the mechanism by which competing vendors share threat data with each other.

**Links:** [Official site](https://www.cyberthreatalliance.org)

## Overview

CTA's premise is that security vendors sharing threat intelligence with each other (rather than only with their own customers) makes everyone's detection better — membership is vendor-oriented, but CTA also publishes public threat reports worth reading even without membership.

## Install / Deploy

```text
Public threat reports are available directly at cyberthreatalliance.org;
membership is for security vendors, not individual practitioners/end-user orgs.
```
