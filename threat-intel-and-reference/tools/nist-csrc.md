# NIST Computer Security Resource Center (CSRC)

Home of the NIST Cybersecurity Framework, SP 800-series, and FIPS standards — the reference most auditors and cyber-insurance questionnaires already assume.

**Links:** [Official site](https://csrc.nist.gov)

## Overview

CSRC hosts the actual text of the NIST CSF, the SP 800-series (800-53 for controls, 800-171 for CUI protection, and many more), and FIPS cryptographic standards — the primary reference point for "what does a properly-documented security control look like" in US-influenced compliance work.

## Install / Deploy

```text
No installation — browse csrc.nist.gov directly, or download specific
publications (PDF) for offline reference.
```

## Lab Exercise

Map your controls against NIST CSF or SP 800-53 once a year as a gap-check, even informally — pick one function (e.g. "Detect") and confirm you have a real, working control for each subcategory.
